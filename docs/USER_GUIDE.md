# User Guide

## Navigating the Dashboard
The main dashboard provides a holistic view of your pricing performance.
- **KPI Cards**: See Revenue, Margin, and Forecast Accuracy at a glance.
- **Trends Chart**: Visualize how your acceptance rate correlates with revenue over time.

## Setting up an Integration
1. Go to **Settings -> Integrations**.
2. Click **Connect Shopify**.
3. Enter your `.myshopify.com` URL and Access Token.
4. The system will automatically sync your products and historical sales data.

## Running an A/B Test
1. Go to the **Products** tab.
2. Select a product and click **Optimize Price**.
3. The AI will suggest a new price. Click **Run A/B Test**.
4. Monitor the test in the **Experiments** tab. When it reaches statistical significance, conclude the test to apply the winning price.
